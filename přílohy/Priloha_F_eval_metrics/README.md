# Příloha F

## Report metrik baseline evaluace modelů

Tato příloha obsahuje souhrnný JSON report s agregovanými metrikami baseline evaluace modelů pro režimy heating a cooling.

## Hlavní soubor

- [eval_metrics.json](./eval_metrics.json)

## Co příloha obsahuje

- globální metriky přesnosti jednotlivých modelů
- metriky po jednotlivých pozicích
- hodnoty typu MAE, P90, P95, bias a podíl podhodnocení a nadhodnocení
- přehled výsledků použitelný pro interpretaci kvality modelů

## Význam v práci

Tato příloha představuje konkrétní evaluační výstup, na který navazuje analytická část práce při porovnání modelů a interpretaci jejich chování.
