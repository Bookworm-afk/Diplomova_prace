# Příloha I

## Tabulkový přehled hlavních skriptů

Tato příloha obsahuje tabulkový přehled vybraných Python a Reliance skriptů použitých v rámci navrženého řešení. Slouží jako orientační soupis hlavních běhových, podpůrných a integračních částí projektu.

## Hlavní soubor

- [prehled_python_reliance_scriptu.xlsx](./prehled_python_reliance_scriptu.xlsx)

## Co příloha obsahuje

- soupis hlavních skriptů použitých v projektu
- základní orientaci v jejich účelu a roli
- přehled vazeb mezi Python částí a prostředím Reliance

## Význam v práci

Tato příloha doplňuje zdrojové a datové přílohy o stručný tabulkový přehled, který usnadňuje orientaci v použitém softwarovém řešení.
